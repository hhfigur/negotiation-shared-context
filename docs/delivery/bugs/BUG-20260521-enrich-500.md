# BUG-20260521-enrich-500

**Erstellt:** 2026-05-21
**Status:** DONE
**Risiko:** P1
**TARGET REPO:** negotiationcoach-backend (primary)
**Layer:** Layer 2 (Market Data Enrichment)
**Bug-Typ:** Logic-Bug
**Betroffene Tiers:** kmu, profi
**ADR-Constraints:** ADR-003 (AI Provider Strategy), ADR-007 (Layer 1/2 Separation)

## Symptom

`POST /api/enrich` gibt HTTP 500 zurück. Der Plan wird unvollständig dargestellt —
Market-Data-Felder (Marktmedian, Reality Score, Marktkontext) fehlen.

**Soll-Verhalten:** `/api/enrich` liefert `market_median`, `reality_score`,
`market_range_min/max`, `market_context_summary` für kmu/profi-Tier-Nutzer.

## Ort

- `negotiationcoach-backend/src/api/routes.ts` — `POST /api/enrich` Endpunkt
- `negotiationcoach-backend/src/api/layer2/` — Market Data Enrichment Logik
- Frontend: `negotiation-buddy/src/pages/ZopaCalculator.tsx:135` — enrich-Aufruf

## Reproduktion

1. Als kmu-Nutzer einloggen
2. Chat-Flow durchlaufen bis Layer-1-Analyse ausgelöst wird
3. `/api/enrich` wird aufgerufen (von ZopaCalculator oder analyze-full)
4. Response: HTTP 500
5. Market-Data-Felder im UI bleiben leer / Plan unvollständig

## Logs / Fehlermeldungen

- Browser Console (Fehler-Tab): `Failed to load resource: the server responded with a status of 500`
- URL: `https://negotiationcoach-backend.onrender.com/api/enrich`
- Kein Frontend-Error-Boundary — stiller Fehler in der UI
- Backend-Logs (Render.com): nicht direkt verfügbar — Diagnose via Code-Lektüre

## Verdacht

- Supabase-Projekt-Migration (Lovable → gpllrgkuozytyrmpfwbb) könnte
  Backend-Env-Variablen invalidiert haben (SUPABASE_URL, SUPABASE_SERVICE_KEY)
- Layer-2-Implementierung nutzt möglicherweise API-Keys oder Endpunkte die
  nach der Migration nicht mehr stimmen
- Oder: ein Zod-Validierungsfehler im Request/Response-Shape
- Verweis: R-2026-05 (NC-L2-FIX) war bereits deployed — möglicherweise Regression

## Plan

Diagnosis Report: `docs/delivery/BUG-20260521-enrich-500-diagnosis-report.md` (`90b5478`)

Root Cause (Observed):
- `/api/analyze` + `/api/analyze-full` speichern `inputs` nicht in `negotiation_sessions`
- `/api/enrich` liest `session.inputs` aus DB → `null` → `null.tier = req.tier` → TypeError → 500
- `inputs`-Spalte (JSONB, nullable) seit Migration 20260408 vorhanden — nie befüllt

Fix-Scope: `src/api/routes.ts` (negotiationcoach-backend), 3 Änderungen

# Briefs

Delivery briefs for items ready to move into delivery.

## File naming
`product/briefs/<ITEM-ID>.md`

## Minimum content
- Goal / Outcome | Problem | Affected Repos | Scope | Non-goals
- Acceptance Criteria | Telemetry / Measurement | Risks / Open Questions

## Lifecycle
- create brief before delivery starts
- keep aligned with current release
- update if scope, AC, or telemetry changes
